# whatsapp-mini-store
A simple whatsapp-based online ordering solution for small vendors.

🏪Kanha Srinagar — WhatsApp Pre-Order Store
A simple, mobile-friendly online storefront designed for Kanha Srinagar, allowing customers to browse products, create a pickup basket, and send their order details directly to the shop's WhatsApp.

📌 About the Project

This project is designed as a lightweight digital solution for small/local shops that want to provide customers with an online product catalogue and simple ordering experience without building a complex e-commerce platform.

Customers can:

- Browse available products
- Filter products by category
- View product details
- Select quantities
- Add products to a pickup basket
- Enter their name and WhatsApp number
- Select a pickup time
- Add additional product/variant requirements
- Send the complete order directly to the shop through WhatsApp

✨ Features

- 📱 Mobile-friendly interface
- 🛍️ Product catalogue
- 🔎 Category-based product filtering
- ➕ Quantity selection
- 🛒 Shopping/pickup basket
- 👤 Customer details form
- 🕐 Pickup time selection
- 💬 WhatsApp order generation
- 📍 Google Maps shop location
- 🎙️ Option to communicate additional requirements through WhatsApp voice notes
- ⚡ Lightweight single-file implementation

🛠️ Technologies Used

- HTML
- CSS
- JavaScript

All HTML, CSS and JavaScript are currently contained in a single "index.html" file.

🔄 How It Works

Customer visits the store
        ↓
Browses products
        ↓
Selects products & quantities
        ↓
Adds products to pickup basket
        ↓
Enters customer details
        ↓
Selects pickup time
        ↓
Website generates WhatsApp order
        ↓
Order is sent to the shop's WhatsApp

🎯 Target Use Case

This concept is aimed at small and local vendors who want a simple online presence and ordering system without the complexity of a traditional e-commerce website.

Instead of requiring a full backend, database and complicated checkout system, the current version uses WhatsApp as the communication channel between the customer and the shop.
